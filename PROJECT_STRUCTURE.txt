1. TỔNG QUAN DỰ ÁN (EXECUTIVE OVERVIEW)
------------------------------------------------------------------------------------------
Dự án nghiên cứu và tái lập mô hình ước lượng độ sâu đơn mục (Monocular Depth Estimation)
dựa trên kiến trúc BTS (From Big to Small: Multi-Scale Local Planar Guidance for Monocular
Depth Estimation) trên 2 bộ dữ liệu chuẩn mực hàng đầu:
  1. NYU Depth V2 (Môi trường trong nhà - Indoor): 24,231 ảnh train / 654 ảnh test
  2. KITTI Raw Dataset (Môi trường ngoài trời / Xe tự hành - Outdoor): 67 archives (174.73 GB)

Mục tiêu: Huấn luyện chuẩn xác 50 Epochs theo công bố bài báo gốc, tích lũy checkpoint tăng dần
qua các phiên 12 giờ trên Kaggle (2x Tesla T4), stream dữ liệu trực tiếp lên Weights & Biases.

    - wandb_key.txt: API Key kết nối Cloud Dashboard Weights & Biases để stream loss/metric real-time.

    - Tool/deploy_to_new_kaggle.py: Script tự động đóng gói checkpoint dataset và đẩy notebook lên Kaggle.
    - Tool/inject_wandb_to_notebook.py: Script nhúng thư viện WandB và patch bts_main.py tự động.
    - Tool/analyze_bts_log.py: Bộ phân tích log huấn luyện trích xuất 9 metrics và đồ thị hội tụ.
    - Tool/fetch_kaggle_output.py: Công cụ tải log và checkpoint model-latest từ Kaggle về local.

[2] THƯ MỤC /bts/ (MÃ NGUỒN HUẤN LUYỆN CHÍNH):
    - bts/pytorch/bts_main.py: Trọng tâm huấn luyện BTS PyTorch, chứa DDP (DistributedDataParallel), 
      LPG (Local Planar Guidance layers), SILog loss criterion, WandB real-time logger và checkpoint auto-resume.
    - bts/pytorch/bts.py: Định nghĩa kiến trúc mạng BTS (DenseNet161 Encoder + Multi-Scale LPG Decoder).
    - bts/pytorch/bts_dataloader.py: Pipeline đọc dữ liệu NYUv2 / KITTI, biến đổi dữ liệu (Random Crop, Rotate, Flip).
    - bts/pytorch/arguments_train_nyu_kaggle_full.txt: Cấu hình tham số chuẩn xác 100% theo bài báo BTS gốc.
    - bts/pytorch/models/: Chứa các checkpoint trọng số đã huấn luyện (model-latest, model-best-*, events.out.tfevents).

[3] THƯ MỤC /kaggle_notebook_new_acc/:
    - bts-nyuv2-training.ipynb: Notebook chạy trên Kaggle kết hợp DDP 2x Tesla T4, nạp checkpoint tự động và stream WandB.
    - kernel-metadata.json: Metadata liên kết notebook với GPU T4 x2 và các dataset gắn kèm.
